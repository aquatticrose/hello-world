curriculum

Twelve weeks, six milestones

Each module unlocks a working program you could ship today.

01Thinking like a machine10 lessons · 4h

Bits, bytes, variables and the assignment operator. You will write your first program and deliberately break it on purpose to see what an error really means.

  • variables
  • types
  • I/O
  • errors
02Control flow and logic14 lessons · 6h

Conditions, loops and the art of nesting less. Build a number-guessing game, then refactor it until it is readable by a stranger.

  • if/else
  • loops
  • refactoring
03Functions & composition12 lessons · 5h

Parameters, return values, scope and pure functions. Small pieces that compose into something big — the core habit of professional engineers.

  • scope
  • recursion
  • pure functions
04Data structures that matter16 lessons · 7h

Lists, dictionaries, sets and queues — plus when each one wins. You will implement them yourself before using a library.

  • arrays
  • hash maps
  • big-O
05Files, errors & debugging12 lessons · 5h

Persistence, exceptions and a repeatable debugging loop. Finish with a command-line tool that reads and rewrites real data files.

  • files
  • exceptions
  • debugger
06Ship it: the capstone20 lessons · 9h

Git, README, tests and a deploy. You publish a real project to GitHub with a portfolio page — and a mentor review at the end.

  • git
  • tests
  • deploy

faq

Questions, answered

Do I need any experience?

No. The course starts at “what is a program”. If you can use a browser and a keyboard, you can take it.

Which language do I learn first?

Python — it keeps the noise down so the concepts stay loud. Rust, JavaScript and Go appear in the playground section for comparison.

How much time per week?

Six to eight hours. Lessons are 8–15 minutes and each ends with a task, so you learn by doing, not by binge-watching.
